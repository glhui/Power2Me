# 言语理解答案复盘

## 使用方式

在已经独立作答后使用。发送本提示词时，附上题目、你的选项与思路；如果已经拿到参考答案或官方解析，也一并附上。没有参考答案时，Agent 应把自己的判断标为“独立判断”。

## 提示词

请先阅读仓库根目录的 `AGENTS.md`。

请复盘我的答案，并严格区分原文事实、我的作答、你的独立判断和参考答案。

按以下顺序输出：

1. 标出文段的背景、变化和核心观点；不存在某一部分时明确说明，不要强行套结构。
2. 找出决定答案的中心句或关键语义关系，并引用必要的短语作为证据。
3. 分别说明四个选项与原文的关系，例如准确概括、范围扩大、范围缩小、偏离重点、概念偷换、因果倒置或无中生有。
4. 找到我思路中的第一处实质错误；如果我的推理正确，则指出最关键的正确步骤，不虚构错误。
5. 判断该问题主要属于知识、信息定位、概括、概念偷换还是审题错误；必要时可标一个次要类型，并说明依据。
6. 给出下一次可以执行的检查动作。动作必须具体、简短，并能在下一题作答时直接使用。
7. 生成一道结构相近但内容不同的四选一练习题。先只给题目和选项，不立即给答案；等我作答后再反馈。
8. 暂时不要修改 Skill，也不要形成长期易错标签；只生成本题学习记录。

本题学习记录使用以下格式：

```markdown
## 日期与题目标识

- 我的答案：
- 参考答案：未提供 / 已提供（填写选项）
- 结果：正确 / 错误 / 参考答案待核验
- 第一处实质错误：
- 错误类型：
- 原文证据：
- 可复用方法：
- 下次检查动作：
- 候选易错观察：仅供后续聚合，不作为长期标签
```
