# 言语理解与表达本地题库

- 去重题量：12452 题
- 扫描试卷：658 套
- 数据来源：https://www.xingcewang.com
- 内容范围：题干、选项、答案索引、题目标识和试卷出处
- 未保存：网站长短解析、AI 标签及训练分数

## 文件

- `言语理解题库.sqlite3`：适合程序查询和后续学习记录关联。
- `言语理解题库.jsonl`：每行一道题，适合 Agent 和脚本处理。
- `答案索引.csv`：答案与题目分离。
- `题目分册/`：每 100 题一个 Markdown 文件，适合分批练习。
- `清单.json`：本次归档统计与字段范围。

这些文件位于 `.local/`，默认不会提交到公开 Git 仓库。
